# Data card

No datasets. All data is generated by interaction with simulated environments:

| environment | source | licence | observation / action | budget |
|---|---|---|---|---|
| CartPole-v1, Acrobot-v1 | Gymnasium 1.x classic control | MIT | 4-d / 2 discrete; 6-d / 3 discrete | 500k steps |
| Hopper-v5, HalfCheetah-v5 | Gymnasium MuJoCo (MuJoCo 3.x, Apache-2.0) | MIT / Apache-2.0 | 11-d / 3-d continuous; 17-d / 6-d continuous | 1M steps |

Environment seeds are `1000·seed + env_index`, so a seed fully determines the reset sequence.
Truncation at the time limit is treated like termination (no bootstrapping from the final
state), as in the reference implementations being compared.
